# P2 register epilogue: decay plus state update

`tcgen05_p2_epi.cu` is copied from `tcgen05_p1_epi.cu`. It computes
`C[b,m,n] = S[b,m,n] * g_total[b,m] + (K^T U)[m,n]`.
The MMA starts with `ScaleOut::Zero`; TMEM holds only the product, and
the state multiply/add happens in the register epilogue.

## Production decay semantics

In `csrc/smxx/fwd_kernel2.cuh`, Phase 6 loads
`g_total(m * 16 + group_id)` and `g_total(m * 16 + group_id + 8)`
(lines 684–685 and 706–707). These multiply the two accumulator rows
at `c0` and `c1` (lines 716–719) of the `s_acc_T` view. The column block
`warp_id * 2 + bi` does not enter the decay index.

Thus decay indexes the key-feature row of `K_restored^T U`, broadcast
across value-feature columns. P2 encodes this as a logical `[128,128]`
CuTe layout with stride `(1,0)` and partitions it exactly like the output.
It does not copy SM80 lane arithmetic into the Blackwell TMEM-copy layout.

The input contract extends P1-epi with FP32 `g_total[batch,128]`.
State and output remain FP32, as requested for this experiment; production
stores its intermediate state as BF16. This reproduces the decay/update
arithmetic and broadcast, not production's BF16 rounding or full recurrence.

`p2_runner.cuh` preserves P1's input generation and timing method, adds
nonuniform decay varying with row and CTA, and compares every output against
an independent double-precision host reference. It also checks that state
and decay remain unchanged. Every timed launch is one independent update.

## Build and initial run

On B300, with CUDA 13.0 and CUTLASS headers at `cutlass/include`:

```bash
nvcc -std=c++17 -O3 -lineinfo -arch=sm_103a \
  --expt-relaxed-constexpr --expt-extended-lambda \
  --ptxas-options=-v,--warn-on-spills -Icutlass/include \
  experiments/sm100_phase6/tcgen05_p2_epi.cu \
  -o experiments/sm100_phase6/tcgen05_p2_epi

./experiments/sm100_phase6/tcgen05_p2_epi \
  --warmup 30 --iters 200 --batch 1024
```

The executable reports correctness, latency and runtime resource attributes
as JSON; spill counts come from the PTXAS build log.
